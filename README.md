# Komanda Vision

Construis la première version visuelle de mon SaaS KOMANDA.

KOMANDA est un outil de gestion commerciale destiné aux petits vendeurs qui vendent principalement via WhatsApp, Instagram et Facebook.

Slogan :
« Le copilote commercial des vendeurs. »

Pour cette étape, crée UNIQUEMENT la fondation visuelle et le Dashboard. Ne crée pas encore de backend, Supabase, authentification, WhatsApp API, IA, paiements ou système complexe.
